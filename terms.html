01

Introduction & Scope

This Privacy Policy outlines how VoiceClaw ("we", "us", or "our") collects, processes, and safeguards information when you invite our Discord application to your Discord server or interact with its voice creation features and commands.

By using VoiceClaw, you acknowledge and agree to the data collection and usage practices described in this document. We respect your privacy and are committed to complying with applicable data protection laws, including the European Union General Data Protection Regulation (GDPR) and the California Consumer Privacy Act (CCPA).

02

Information We Collect & Process

To provide dynamic voice channel generation and server permission management, VoiceClaw processes a strictly minimal set of non-sensitive metadata:

Data Point Purpose Storage Type
User Discord ID Identifying channel owner, rate limiting, and saving user custom channel settings. Stored in DB
Server (Guild) ID Linking setup configurations (category and root join channel) to the server. Stored in DB
Channel IDs Managing permissions, temporary voice channels, and deletion upon vacancy. Ephemeral (Until Empty)
Custom Channel Names & Limits Applying user or server preferences when a temporary channel is auto-generated. Stored in DB
Voice Audio Data NEVER COLLECTED. VoiceClaw has zero microphone/audio streaming access. Never Stored
Private Text Messages / DMs NEVER STORED. DMs are only sent for cooldown alerts; no message logs are kept. Never Stored
Important Notice: VoiceClaw never sells, rents, or distributes your personal identification or Discord user information to third-party advertisers or commercial entities.
03

Voice Audio & Communication Privacy

VoiceClaw operates strictly as a channel orchestrator. We want to be unequivocally clear regarding your conversations:

  • The bot does not join voice calls as an audio listener or speaker.
  • The bot does not process, stream, transcribe, or capture voice packets.
  • All voice traffic occurs directly over Discord's end-to-end infrastructure, governed exclusively by Discord's own terms and security infrastructure.
04

Data Retention & Automatic Purging

We believe in minimal data footprint. Our retention rules operate automatically:

  • Temporary Channel Mappings: When a dynamic channel is emptied and deleted, the associated record in voiceChannel table is purged within 3 seconds.
  • Guild Configuration: Server configuration records persist only until the bot is removed from the server or a server administrator runs a reset command.
  • User Settings: Custom channel names and limits persist until requested to be removed by the user or upon 180 consecutive days of inactivity.
05

Your Rights & Data Removal (GDPR / CCPA)

Under international privacy regulations, you have the following rights:

  1. Right of Access: You may request a copy of all stored preferences associated with your Discord user ID.
  2. Right to Erasure ("Right to be Forgotten"): You may request immediate deletion of your user preferences and database references at any time.
  3. Right to Rectification: You can update or override your custom settings anytime using bot commands (e.g., .voice name, .voice limit).

To request data erasure, click the "Request Data Deletion" button above or join our official support server.

01

Database Architecture & Security

The bot stores relational metadata in an isolated, secure database. Access is strictly restricted to automated bot operations using parameterized queries, preventing SQL injection vulnerabilities.

No plaintext passwords, sensitive Discord tokens, or payment details are ever touched or stored by VoiceClaw.
02

Discord Bot Permissions Explained

When inviting VoiceClaw, the bot requests specific Discord OAuth2 permissions. Here is why each is required:

  • Manage Channels: Used to dynamically create temporary voice channels under your specified category and delete them once empty.
  • Move Members: Automatically moves the user from the "Join to Create" channel directly into their newly created temporary channel.
  • Manage Permissions: Allows the owner to run .voice lock, .voice unlock, .voice permit, and .voice reject.
  • Send Messages & Embed Links: Sends control instructions, embed guides, and responses to command executions.
